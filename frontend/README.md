# TrackFit Frontend ⚡

React 19 + Vite frontend application for **TrackFit** — Athlete Fitness & AI Coaching Web App.

Refer to the main [Root README.md](../README.md) for full project architecture, features, and setup instructions.

## Quick Start

```bash
npm install
npm run dev
```
Runs the app on `http://localhost:5173`.
